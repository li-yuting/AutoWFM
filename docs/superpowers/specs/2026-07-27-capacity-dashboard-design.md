# 承接情况看板 设计文档

> 日期：2026-07-27
> 状态：待评审

## 1. 背景与目标

基于 `data/` 下 9 个 SQLite 库（5 分钟颗粒度时间序列）与 `data/预估流入量.csv`（15 分钟颗粒度预测量），构建一个 Web 看板，按小时（日视图）或按日（月视图）展示当日/当月的承接情况。

看板分为**接听（呼入）**与**外呼**两大类数据：

- **接听（呼入）**：热线、在线、12378
- **外呼**：常规二线组、贷后二线组、二线客诉组、常规工单组

## 2. 总体架构

- 技术栈：**Flask + pyecharts (ECharts)**，Jinja2 模板。
- 新增 `dashboard/` 包，独立于采集器：
  - `dashboard/app.py` - Flask 入口与路由
  - `dashboard/queries.py` - 数据层（读库 + 聚合）
  - `dashboard/templates/dashboard.html` - 单页模板（多图容器 + 表格）
  - `dashboard/__init__.py`
- Flask 进程**只读** `data/*.db`，与 `main.py` 采集器**分进程并行**运行。每个库由单线程写入、SQLite 允许并发读，读安全。
- 依赖新增：`flask`、`pyecharts`（安装到现有 `.venv`）。
- 刷新：页面 `<meta http-equiv="refresh" content="300">` 每 5 分钟自动刷新；每次请求实时查库，采集器写入后刷新即可见最新。

## 3. 路由与入口

| URL | 行为 |
|---|---|
| `/` | 重定向到当天日视图 `/?view=day&date=<今天>` |
| `/?view=day&date=YYYY-MM-DD` | 日视图（小时粒度） |
| `/?view=month&date=YYYY-MM` | 月视图（按日粒度） |

页面顶部控件：

- 日期选择框（日视图选日期；月视图选月份）
- 日视图 / 月视图 切换入口

## 4. 数据层

### 4.1 组定义与指标来源

| 组 | 类别 | 量指标（来源库.列） | 坐席指标（来源库.列） | 预测量来源 |
|---|---|---|---|---|
| 热线 | 接听 | 热线.db：转人工量、接通量 | 热线明细.db：签入、空闲 | CSV 热线 `累计预估量` |
| 在线 | 接听 | 在线.db：转人工量、转人工失败 | 在线.db：**在线**（单列） | CSV 在线 `累计预估量` |
| 12378 | 接听 | 12378.db：转人工量、接通量 | 12378明细.db：签入、空闲 | 12378.db：7 天前同小时累计转人工量 |
| 常规二线 | 外呼 | 工单明细.db：回访组一组；会话记录.db：转接一组+转接二组 | 常规.db：签入、空闲 | - |
| 贷后二线 | 外呼 | 工单明细.db：贷后回访组；会话记录.db：贷后转接组 | 贷后.db：签入、空闲 | - |
| 二线客诉 | 外呼 | 工单明细.db：二线客诉处理组 | - | - |
| 常规工单 | 外呼 | 工单明细.db：常规工单处理组 | - | - |

派生指标：

- **转人工成功量**：热线/12378 = `接通量`；在线 = `转人工量 − 转人工失败`。
- **接通率** = 转人工成功量 / 转人工量。
- **流入率** = 转人工量 / 预测量。
- **12378 图表**并入 `工单明细.12378回访组` 工单量，作为额外一根柱。

### 4.2 聚合规则

**日视图（小时粒度）**：

- 小时桶 = `floor(时间, 1 小时)`（如 10:05、10:35 都归入 10 点）。
- 每个小时取该桶内**时间戳最大的一条 5 分钟快照**作为该小时的值。
- 当前未到整点的小时，取已到的最新一条（如最新数据为 10:35，则 10 点显示 10:35 的值）。
- 预测量（CSV，15 分钟颗粒度）：每小时取该小时内时间戳最大的一条 CSV 行的 `累计预估量`。

**月视图（按日粒度）**：

- 累积量指标（转人工量、接通量、转人工失败、工单、会话、预测量）：取**当日时间戳最大的一条**（≈当日收盘累计）。
- 瞬时指标（签入、空闲、在线）：取**当日全部 5 分钟快照的算术平均**。

**跨日累计**（月视图第一部分卡片）：

- 累积量指标 = 当月各日收盘累计值之**和**（因每日累计在次日凌晨重置）。
- 瞬时指标 = 当月各日日均之**平均**。

### 4.3 预测量规则

- 热线 / 在线：来自 CSV `累计预估量`（累计），按 4.2 聚合到小时或日。
- 12378：无 CSV 预测量。某日某小时 H 的预测量 = **该日 7 天前同小时 H 的累计转人工量**（来自 12378.db，逐小时对齐）。
- 12378 全天预测量（月视图按日） = 7 天前当日收盘累计转人工量。
- **时段预测量**（仅第一部分卡片，接听汇总）= **当前小时的预测量**（小时增量，非累计）：
  - 热线+在线 = 当前小时所属的 4 个 15 分钟 `时段预估量` 之和。
  - 12378 = 7 天前当前小时累计转人工量 − 7 天前前一小时累计转人工量（即 7 天前当前小时的转人工量增量）；若前一小时无数据则取 7 天前当前小时累计值。

## 5. 日视图布局

### 5.1 第一部分 整体累计（顶部卡片）

当日截至当前小时的累计值，分接听、外呼两区。

**接听**（热线+在线+12378 汇总）：

| 指标 | 定义 |
|---|---|
| 预测量 | 截至当前小时的累计预测量之和（热线CSV+在线CSV+12378 七天前） |
| 时段预测量 | 当前小时的预测量（见 4.3） |
| 流入率 | 转人工量 / 预测量 |
| 转人工量 | 截至当前小时累计 |
| 转人工成功量 | 截至当前小时累计 |
| 接通率 | 转人工成功量 / 转人工量 |

**外呼**（四组汇总）：

- 各组工单量 + 转接量累计
- 签入 / 空闲（仅常规二线、贷后二线有坐席库；二线客诉、常规工单仅显示工单量）

### 5.2 第二部分 接听图表

热线、在线、12378 各一张图：

- **柱形**：预测量、转人工量、转人工成功量（12378 额外一根"12378回访组"工单量柱）
- **折线**（双 Y 轴）：
  - 热线、12378：签入（实线）、空闲（虚线）
  - 在线：仅"在线"一根线
- **X 轴**：小时。12378 工作日 **8:00–21:00**、周末动态收窄到 **9:00–18:00**（按 `date.weekday()` 判定）；热线、在线为 **9:00–21:00**。

### 5.3 第三部分 外呼图表

常规二线、贷后二线、二线客诉、常规工单各一张图：

- **堆积柱形**：下=**转接量**（原"会话记录"），上=**工单量**（原"工单明细"）。二线客诉、常规工单无转接量 -> 仅工单量单柱。
- **折线**（双 Y 轴）：签入（实线）、空闲（虚线）。二线客诉、常规工单无坐席 -> 不画折线。
- **X 轴**：小时 **9:00–21:00**。

### 5.4 第四部分 时段明细表

两张大表，行=小时（9…21）：

- **接听明细表**：列 = 热线(转人工量/接通率/签入/空闲)、在线(转人工量/接通率/在线)、12378(转人工量/接通率/签入/空闲/12378回访组)。
- **外呼明细表**：列 = 常规二线(工单量/转接量/签入/空闲)、贷后二线(工单量/转接量/签入/空闲)、二线客诉(工单量)、常规工单(工单量)。

宽表，首列（小时）冻结。

## 6. 月视图布局

与日视图同 4 部分结构，X 轴由"小时"换为"日期"（整月每日一点）。

- 第一部分卡片：整月累计（累积量求和、瞬时量取日均）。
- 第二/三部分图表：按日的柱形 + 折线。
- 第四部分：两张大表，行=日期，列同 5.4。
- 月视图 X 轴为日期，5.2/5.3 的小时范围规则不适用。

## 7. 已知数据限制

看板在相应位置标注"无数据"，不报错：

1. **工单明细.db / 会话记录.db 仅从 2026-07-24 起有数据** - 外呼四组与 12378回访组在 07-24 之前为空；7 月月视图外呼部分仅 07-24…07-31。
2. **12378 预测量需"7 天前"数据** - 12378.db 自 2026-07-01 起，故 07-01…07-07 的 12378 预测量无数据。
3. **CSV 预测量范围 2026-06-01…2026-08-15** - 超出该范围热线/在线无预测量。

## 8. 文件结构

```
dashboard/
  __init__.py
  app.py            # Flask 路由：/ 、?view=day&date=、?view=month&date=
  queries.py        # 数据层：load + 聚合，返回模板所需结构
  templates/
    dashboard.html   # 单页：顶部控件 + 4 部分 + pyecharts 图容器
```

`queries.py` 关键函数（示意）：

- `hourly_latest(db_path, cols, date)` - 日视图：每小时最新快照
- `daily_latest(db_path, cols, ym)` - 月视图：每日收盘累计
- `daily_avg(db_path, cols, ym)` - 月视图：每日瞬时均值
- `load_forecast(line, date_or_month)` - CSV 预测量
- `forecast_12378(date)` - 7 天前同小时累计转人工量
- `build_day(date)` / `build_month(ym)` - 组装四部分数据
